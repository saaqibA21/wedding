A luxury mobile-first wedding invitation website featuring a dynamic 9:16 envelope-opening video, smooth feathered merge effects, ivory & antique gold theme, real-time countdown, Google Maps navigation, and an interactive day schedule.

## ✨ Features

- **🎬 9:16 Vertical Video Hero**: Envelope-opening video with custom burgundy wax-seal play prompt and sound toggle.
- **🕊️ Seamless Merge Effect**: Soft feathered gradient transitions dissolving the video smoothly into the ivory canvas with zero hard lines.
- **🎨 Luxury Ivory & Gold Theme**: Warm parchment aesthetic matching the physical invitation card, complete with antique gold calligraphy and floating rose petals.
- **🕌 Auspicious Occasion Details**:
  - **Nikkah**: 10:30 AM – 11:30 AM at **Anjuman Masjid**, T. Nagar, Chennai
  - **Valima**: 12:30 PM onwards at **Parsi Club**, Royapuram, Chennai
- **📍 Interactive Actions**:
  - One-tap **Google Maps Directions** for both venues.
  - One-tap **Copy Address** for rideshare apps (Uber / Ola).
- **⏱️ Live Countdown Timer**: Counting down to Sunday, 3rd January 2027, 10:30 AM IST.
- **📱 Mobile App Experience**: Fixed bottom dock navigation for quick one-thumb jumping.

## 🚀 Running Locally

You can run the included Node.js server with HTTP 206 range-request video streaming:

```bash
node server.js
```

Then open your browser to:
[http://localhost:3000](http://localhost:3000)

Or open `index.html` directly in any web browser.
